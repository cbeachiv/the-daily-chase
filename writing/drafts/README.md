# drafts

One folder per piece: `drafts/<piece-slug>/`. Create only the files a piece needs:

- `brief.md`: assignment, editor, deadline, length, reader
- `notes.md`: raw material
- `research.md`: sources and the claims they support
- `interview/`: recordings, transcripts, and the quote bank
- `outline.md`: current structure
- `draft-version-one.md`, `draft-version-two.md`, ...: Chase's drafts, one file per version
- `review.md`: editorial feedback

## Pieces

- `town-crier-coaches/`: Erik Vanags and Jeff Hinebaugh's final season coaching Mariemont boys soccer. Mariemont Town Crier, December 2026 issue, due Nov 1, 2026.
